# Data Analyst Assessment – Olist E-Commerce

This repository contains the analysis, code, dashboard documentation, and management presentation prepared for the Data Analyst Assessment.

## Dataset

**Brazilian E-Commerce Public Dataset by Olist**

Source: Kaggle  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Business Objective

To identify business opportunities, performance gaps, trends, and operational improvements using e-commerce data.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Sheets
- Google Looker Studio

## Project Deliverables

- Data processing and cleaning
- Exploratory and descriptive analysis
- Business insights
- Actionable recommendations
- Interactive Looker Studio dashboard
- Management presentation
